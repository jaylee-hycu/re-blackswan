# 아파트 시장 신호등

글로벌 금리에서 서울 아파트까지, 위험이 어디까지 번졌나 (내부 프로젝트명: blackswan 부동산)

한국 아파트 시장을 글로벌 금융시장의 부분집합으로 보는 계기판입니다.
글로벌 입력 → 한국 금리 관문 → 국내 취약성 → 수급·거래 → 가격 순서로, 각 지표가 과거 분포에서 어디에 있는지 보여 줍니다.

- 페이지: `docs/index.html` (GitHub Pages)
- 갱신: 매주 목요일 16:00(한국 시간) GitHub Actions (`.github/workflows/update.yml`)
- 판정 기록: `data/history/signals.csv` (덧붙이기만 함)

자료: 한국부동산원 R-ONE, 한국은행 ECOS, OFR Financial Stress Index, FRED, 일본 재무성.
연구용 시제품이며 투자 권유가 아닙니다.
